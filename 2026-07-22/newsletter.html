✚  What's New
 
Your production graph is now an API
Featured
Every question your team asks about production now has an HTTP answer. Graph API v0.2 pins an executable OpenAPI contract, and @anyshift/graph-sdk turns each response into a typed AskResult so agents and pipelines get compile-time shapes from the live graph instead of another dashboard to scrape. Rank a flapping monitor, trace a bad deploy to its failures, or hand an agent ground truth in one call.
Read the Graph API launch
Connect integrations with OAuth, not pasted tokens
Paste-an-API-token onboarding is out for the common path. Connect with Atlassian, Linear, Notion, Sentry, GitLab, and incident.io now run OAuth with backend-owned refresh. Personal tokens stay as the fallback for self-hosted instances and automation. One Atlassian grant covers both Jira and Confluence.
